# MISE Kitchen Care

An independent third homepage concept for a fictional commercial kitchen repair and maintenance brand. Built from a new layout with new typography, new imagery and a different film. The Hawk and KINETIC projects are not modified.

## Hosting

Static HTML/CSS/JavaScript, no dependencies or build step. On Vercel use the Other framework preset, no install/build command, and repository root. Local managed preview serves a copied `dist/` directory; preview configuration is ignored by Git.

## Experience

- Navy, cobalt and lilac editorial design with Instrument Serif and Manrope typography.
- Self-hosted looping kitchen film, poster fallback, accessible film dialog and pause controls.
- Service finder with a local recommendation and prefilled request.
- Swipeable/keyboard-accessible service gallery with arrows and desktop pointer dragging.
- Equipment accordion, interactive maintenance brief and two-step request preview.
- Stationary, centered “In good hands” seal beneath the film, outside its clipped frame.
- Custom orbital cursor with arrow, Watch and Drag states, responsive click feedback and magnetic CTA arrows.
- Eased desktop wheel scrolling, scroll progress, subtle photo parallax, reveal transitions and chapter navigation.
- Native touch scrolling, keyboard/scrollbar control and form editing; all decorative motion can be paused.
- Reduced-motion preferences, global motion pause, keyboard navigation and responsive layouts.

## Scope

This is a client-review homepage, not a real booking service. Request details remain in browser memory only. There is no backend, storage or network submission. Branding, scope, geographic coverage and commercial terms are illustrative and need confirmation before business use. No testimonials or invented performance figures are used. Search indexing is disabled.
